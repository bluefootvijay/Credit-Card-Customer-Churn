Credit Card Customer Churn Analysis

This project analyzes the BankChurners.csv dataset to understand and identify the key factors that contribute to customer churn (attrition). By examining customer demographics, credit card usage, and transaction patterns, the goal is to uncover insights that could help a bank develop strategies to retain customers.

Exploratory Data Analysis (EDA)

The core of the analysis is focused on answering key business questions by comparing "Existing Customers" and "Attrited Customers."

Business Question 1: What factors are associated with higher customer churn?

To answer this, the notebook performs a univariate analysis on key categorical features against the Attrition_Flag.
Features Analyzed: Age_Bins, Gender, Marital_Status, Dependent_count, Education_Level, and Income_Category.
Visualization: Stacked bar charts (showing both absolute counts and percentages) are generated for each feature to visually compare the churn rate across different groups.
